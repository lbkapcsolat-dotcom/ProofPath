# Current vs Historical Public Surface Policy

STATUS: ACTIVE_PUBLIC_SURFACE_POLICY
EFFECTIVE_DATE: 2026-09-08

## Current authority

For system identity, the only current public name is **Equilibrium Stability System (ESS)**.

The default branch `main` and the current ESS public identity manifest define the current public naming surface.

## Historical metadata

Older branch names, tags, releases, commits, URLs, or labels may remain visible solely to preserve provenance and reproducibility.

Such historical metadata is:

- **INACTIVE**;
- **NON-AUTHORITATIVE**;
- **NOT A CURRENT SYSTEM IDENTITY**;
- **NOT A RUNTIME, PRODUCTION, POINTER, OR GLOBAL-BIND AUTHORITY**;
- **NOT EVIDENCE THAT HISTORICAL IMPLEMENTATION CONTENT IS CURRENTLY EXPOSED**.

Historical branch refs that are retained for provenance may be pointed at the current clean `main` surface so that the retained ref name does not expose a separate historical implementation tree.

## Interpretation rule

If a historical label conflicts with the current ESS identity manifest, the current ESS identity manifest controls.

Preservation of historical metadata is not promotion, endorsement, reactivation, or restoration of a predecessor identity.

## Claim ceiling

This policy concerns public-surface identity and provenance only. It does not establish runtime admission, production readiness, certification, deployment authority, external actuation, pointer mutation, or global bind.
