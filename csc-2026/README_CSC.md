# ProofPath School Evidence Coach — CSC 2026 delta

## Purpose
A student-facing Assignment Mode for bounded evidence reasoning in school assignments.

## Event-window work
Created on/after the CSC Back-to-School Hackathon build window opening on 2026-09-04.
This event delta includes:
- a standalone Assignment Mode UI;
- student-facing SUPPORTED / CONTRADICTED / INSUFFICIENT explanations;
- visible claim ceiling and next-evidence-step guidance;
- mobile/readability styling;
- event-specific tests and disclosure text.

## Pre-existing work disclosure
The broader ProofPath project, its prior bounded evidence-classification concepts, existing interfaces, prior tests, and prior claim-ceiling work pre-date this hackathon. They are not represented as CSC-created work. This CSC directory is a competition-specific educational delta built during the official event window.

## AI-use disclosure
AI assistance was used during implementation, testing, documentation, and wording. The entrant retains responsibility for project decisions, understands the implementation, and can explain how it works. No claim is made that AI independently verifies truth.

## Claim ceiling
`EDUCATIONAL_EVIDENCE_ASSESSMENT_ONLY`

This is a reasoning aid. It does not certify truth, replace teachers, or establish source authority.

## Zero-spend
This implementation uses browser-native HTML/CSS/JavaScript and Node's built-in test/assert functionality. No sponsored or paid credits are required.
