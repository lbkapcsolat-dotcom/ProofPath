# School Evidence Coach — CSC Back-to-School Hackathon 2026

A small student-facing reasoning aid for checking whether a short source passage **supports**, **contradicts**, or is **insufficient** for an assignment claim.

## Event-window scope

This directory is the CSC 2026 event delta. Its UI, bounded evidence-assessment engine, and event tests are event-window work.

The surrounding ProofPath repository existed before the hackathon. It is **not** represented as new CSC work. The event submission must disclose that pre-existing repository context and identify this directory as the substantial CSC-specific development.

## Claim ceiling

`EDUCATIONAL_EVIDENCE_ASSESSMENT_ONLY`

The tool does **not** certify truth, verify source authority, replace a teacher, or guarantee that an assignment claim is correct. It exposes a bounded evidence relationship and recommends the next evidence step.
