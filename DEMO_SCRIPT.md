# 3–5 minute demo script

0:00–0:25 — Problem
Environmental charts make it easy to confuse a noisy line with a strong conclusion. EcoDrift keeps signal, anomaly, change-point and uncertainty separate.

0:25–0:55 — Provenance
Show the source panel: NASA POWER precipitation, Budapest coordinates, 2000–2024 period, DMAP-AI SPI-12 derivation, and the explicit claim ceiling.

0:55–1:35 — Trend + uncertainty
Show Annual precipitation. Explain the slope and bootstrap interval. If the interval includes zero, point out that EcoDrift refuses to call the direction resolved.

1:35–2:10 — Anomalies
Point to robust MAD-based outliers. Explain that this is resistant to a few extreme years and does not label every unusual value as a regime shift.

2:10–2:45 — Change-point
Point to the dashed CUSUM candidate year. Explain candidate versus proof of structural change.

2:45–3:20 — SPI view
Switch to SPI-12. Show how the same time axis becomes standardized wet/dry context. Note that SPI category is not direct impact measurement.

3:20–3:50 — Custom CSV
Upload a simple year,value CSV. Show that the same pipeline runs on user data with at least eight rows.

3:50–4:10 — Close
EcoDrift's idea is simple: environmental data is more useful when uncertainty and claim limits are visible next to the signal.
